# MyRush

A small offline platformer game for a 6-year-old. The whole game is one file: `index.html`.

## Get the Android app

1. Open the **Releases** page of this repository on the Android phone or tablet.
2. Download `MyRush.apk` from the newest release and open it. Allow the install when Android asks.
3. Open the app. A grown-up sets a PIN and gives play time before the game will start.

Every push to `main` builds a new APK automatically (see the Actions tab) and adds it to a new release.

## Change the game

Edit `index.html` and push. The Android app is only a full-screen wrapper around that file.
